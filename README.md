## Playwright Fundamentals: End-to-End Test Automation

A collection of automated test scripts built with [Playwright](https://playwright.dev) demonstrating core end-to-end (E2E) testing concepts, browser interactions, and best practices.

### Concepts Covered
This repository includes practical examples and test suites covering the following Playwright fundamentals:
** **Locators & Selectors:** Finding elements using user-facing attributes (`getByRole`, `getByText`, `getByLabel`, `getByTestId`).
* **User Actions:** Simulating clicks, text input, checkboxes, dropdown selections, file uploads, and keyboard/mouse events.
* **Assertions:** Verifying page states, visibility, text content, URLs, and attributes using web-first `expect` assertions.
